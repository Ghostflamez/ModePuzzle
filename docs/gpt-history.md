# 需求演变记录（迁移自 ChatGPT 对话）

来源：ChatGPT 对话「模组拼合优化程序」（6aec2968-c154-83ec-88e6-6d22a77e4622），2026-11-05 迁移到本地。
线上版：https://module-layout-lab-hz.attentivepopcorn.chatgpt.site/ （ChatGPT Sites 托管，迁移时与本地 dist/ 逐字节一致）。
详细规则以 README.md 为准；本文件记录**用户的原始需求和修正过的误解**，避免重蹈覆辙。

## 1. 原始需求

- 插槽：7 列 × 5 行，四角不可用，共 31 格。
- 三项数值：效率、质量、性能。系统总值 = 所有插入件各项分别相加。
- A 类「模组」（常见 5 格，形状任意共边连通），词条：
  1. 侧边挂载：接触舱体**左侧**边缘 → 自身 +20% 临时加成
  2. 负反馈：吸收相邻**模组** 25% 的负面基础属性（不吸收节点）
  3. 顶部挂载：接触舱体**顶部**边缘 → 自身 +20% 临时加成
  4. 接收器：每相邻一个节点 → 自身 +10% 临时加成
  5. 后续可扩展
- B 类「辅助节点」：固定 1×2，吸收每个相邻模组 20% 的**原始**属性；节点不吸收节点。
- C 类：预留扩展。
- 插入件不可重叠；可 90° 旋转、上下左右翻转。
- 目标：录入候选件（可选是否允许冗余），选择一项数值，求其最大的拼合方式。**注重可扩展性。**

## 2. 用户补充/澄清（均已实现）

- 只认共边相邻；临时加成只作用于自身；相邻读取的是**初始值**（不传播加成）。
- 支持重复数量；属性可为负数。
- 自定义目标：三项各自上下界（可单设/不设）+ 可勾选 ±5% 浮动；首要/次要优先级（严格字典序）。
- **迭代时必须保留用户浏览器中已录入的模组数据**（localStorage 键与网址不变，升级前备份）。
- 点击布局中的模组 → 左侧对应卡片高亮并置顶。
- 取整：向零取整，不存在小数运算。
- 双挂载按加法叠加（+40%，非 1.2×1.2），已由游戏截图验证。
- 挂载只认舱体最外侧四条大边，四角缺口小边不算。
- 吸收算法：先把相邻同项初始值**求和** → 乘比例 → 向零取整（节点与负反馈都如此）；接收器仍逐节点取整。
- 负反馈的 25% 正向增幅**在生成时已计入输入值**，不能再乘一遍。
- 「必选」= 优化时必须用到；「锁定」= 优化时排除。**GPT 曾把两者搞混过**，现为两个独立字段 `required` / `locked`。
- 「锁定一个」只分离一件；完全相同（含状态）的模组自动堆叠；名称可留空，自动 `#N` 顺延且不回退。
- 结果下方「锁定本次布局中的所有插入物」：只排除实际用到的副本。

## 3. 外观演变（最终状态）

- 配色按初始属性：效率模组绿、特殊模组蓝（三项均 ≤0）、辅助节点灰、性能模组红、质量模组黄、AI 模组紫（质量+性能均正），其他斜条纹。
- 形状预设 7 种（格数 3,5,4,5,4,4,2）+ 后补四格 L 型（底三格、右上一格），共 8 种。
- 外观尝试过：细轮廓 → 圆角轮廓 → 融合色块 → 代码像素画（用户评价「太丑」）→ **最终采用第一版位图贴图**（`dist/assets/*.png` + `dist/pixels.js` 裁切）。
- 同形状不同类型：线路板相同，仅色卡不同。四格方形分两种：单正向词条的较小；带负面词条的为标准尺寸。AI 只能是四格方形。
- 模组本体不显示数字，保留图注和点击定位。
- 最后一轮：贴图边缘去毛刺（形态开运算 + 最大连通主体，只改 alpha）；舱体层次为「深灰舱底 → 黑色插槽格（始终显示）→ 模组贴图」。
