# ModePuzzle (模组拼合实验室)

> **Unofficial fan tool** for *Probably Stolen*. Not affiliated with or endorsed by Questing Goose Studio.
> Contains no game assets: the module pixel art is original and generated by code, descriptions are written
> from scratch, and only the game's own terms (taken from its English localization) are used.
> Code under the [MIT](LICENSE) license; font licenses in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

A module-bay layout optimizer. Enter (or import from your save) the modules and nodes you own, pick which
stats to maximize or which ranges to hit, and it searches for the best layout of a machine's module bay,
with the game's exact integer scoring (mounts, Receiver, Negative Feedback, Support Node absorption).

The interface is available in **English and Chinese**; use the switch at the top right.

## Download

Get the latest build from [Releases](https://github.com/Ghostflamez/ModePuzzle/releases/latest):

- `ModePuzzle-v*.exe`: Windows desktop app (single file; needs WebView2, preinstalled on Windows 10/11).
- `module-layout-offline.html`: browser version; just open the file.

## Features

- **Import your save** (read-only, never written back): every machine with a module bay, the modules
  installed in it and your free modules, including effects and Learning Algorithm caps.
- **Machine view**: optimize one machine using its own modules plus free ones; lock/unlock machines so
  their modules are (not) borrowed; try bay expansion stages; see the machine's output with formulas
  taken from the game code.
- **Targets**: maximize Efficiency / Quality / Performance, or set min/max ranges per stat (with exact
  and fuzzy matching) plus primary and secondary priorities.
- **Exact search** (branch and bound) that can prove a layout globally optimal; time-limited runs return
  the best layout found so far.
- **Required / Locked** pieces, automatic stacking of identical modules, layout breakdown per piece.
- **Optional game sprites**: if you allow it, the tool reads the module sprites from your *own* local
  game install (read-only) and shows them instead of the original art. They stay on your PC only.

## Desktop data

The desktop app keeps its data in `%APPDATA%\ModePuzzle\storage.json`; it uses port 42173 or any free port.
Move data between the browser and desktop versions with *Export config* / *Import config*.

## Development

```sh
npm test                                   # Node's built-in test runner
python -m http.server 5173 --directory src # then open http://127.0.0.1:5173
python scripts/build.py                    # dist/module-layout-offline.html
python scripts/build_exe.py                # release/ModePuzzle-v<version>.exe
```

UI text is written in Chinese inside `tl('…')` and translated in `src/i18n/en.js`; see README.md (Chinese)
for the full rules and design notes.
